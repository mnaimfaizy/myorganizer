MyOrganizer Escape Copy reader

Opens a MyOrganizer vault Escape Copy — the file a local Export or a Google Drive backup produces — with your passphrase or your Recovery Key. It needs no MyOrganizer account, no MyOrganizer server, and no Google account. It works with the network cable out, and it is meant to keep working if MyOrganizer does not.

Before you type your passphrase into this file

A file that accepts a vault passphrase is exactly the thing an attacker would like to substitute. Use only a copy whose checksum matches the one published beside it on the MyOrganizer GitHub Releases page, or a copy you saved yourself from a release you already verified.

Verify with sha256sum (Linux), shasum -a 256 (macOS), or Get-FileHash (Windows PowerShell), and compare against the published SHA256SUMS.txt.
