# Design Brief Command

Use this workflow when the user wants a prompt for the Designer agent — a diagram, animated walkthrough, explainer page, or architecture visual briefed rather than built.

1. Read and follow `.agents/skills/design-brief/SKILL.md` exactly.
2. The deliverable is a Markdown brief, not a design. Do not produce the artifact.
3. If the subject has a source of truth in the codebase, follow `.agents/skills/design-brief/GROUNDING.md` — the repo-wide constant collision check is mandatory, not advisory.
4. State which branch you took (grounded or ungrounded) when handing the brief over.
