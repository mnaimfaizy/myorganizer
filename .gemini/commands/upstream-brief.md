# Upstream Brief Command

Write one Upstream Brief comparing repo-owned instructions to official docs.

1. Read and follow `.agents/skills/upstream-brief/SKILL.md` exactly.
2. Require `subject@version` tokens from the user. Do not fetch “latest.”
3. Resolve current versions from `upstream-brief.config.yml`.
4. Fan out Independent Hops — one research worker per subject — against primary upstream pages only.
5. Write the brief. Apply no instruction or code edits.
6. If there is a finding, propose a HITL issue and file it only on confirm. Do not start a grill.
