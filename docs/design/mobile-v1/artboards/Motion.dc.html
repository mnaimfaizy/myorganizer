Rules
•The haptic fires once, when the tick commits on touch up. It never fires on touch down, while a swipe reveals, or during a scroll.
•The system haptic setting wins. Reduce Motion never removes a haptic, because a haptic is not motion.
•Reduce Motion comes from AccessibilityInfo.isReduceMotionEnabled() and its reduceMotionChanged event. Android reports it as true when animations are removed.
•No haptics or animation library is installed. React Native 0.79 ships Animated, LayoutAnimation and Vibration, and Vibration is not a haptic engine, so the haptics module is still to be chosen.
•With Checked collapsed, the row still leaves To buy and only the Checked count changes.
