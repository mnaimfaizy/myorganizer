Sub-agent orchestration map

One main orchestrator classifies every task into a gate tier, and that tier decides whether it edits directly or delegates to a pipeline of narrow, single-purpose sub-agents — most of them cheap and read-only, a few reviewers holding veto power. Every sub-agent returns to the orchestrator. There are no agent-to-agent calls.

The gate tier router

Every task passes through classification before any delegation. Same tiers for interactive and autonomous / AFK runs.

Fixture / type retarget, rename, dead-code delete, selector-only string change
Main agent edits directly + focused lint/tests. No specialists — and no Structured Spec, because there is nobody to hand it to. The shape checks don't disappear, they relocate: the orchestrator runs yarn component:hygiene <path> itself.

One specialist hop when that artifact type changes — TestScaffold or ComponentBuilder, not both by default (+ reviewer if the pipeline needs one). The full Structured Spec is still built.

New UI module, vault / crypto, API contract, multi-file product behavior

Same job title, opposite tiers

The two reviewers were assessed with the same question — what is left once the checklist is scripted? — and landed at the far ends of the scale.

Downgrade accepted
TestReviewerT0
Its checklist was scripted, so the residual work is genuinely deterministic. Runtime judgment moved out to TestRunner.
ADR 0004
Downgrade declined
ComponentReviewerT2
The same downgrade was evaluated and refused. What is left after scripting is design judgment: is the compound split right, is this component mixing concerns, should this have been Radix, does a primitive secretly know about the domain.
A cheap model answers those with an unearned PASS, and the gate runs once per component — a small saving against an asymmetric risk. ADR 0014
Inside ComponentReviewer — each check assigned to the layer that can decide it
check-component-hygiene.mjs
Shape rules: forwardRef/displayName, cn() merging, barrel export, deep imports, inline props types, effect cleanup, oversized JSX.
tsc --noEmit + eslint
Type correctness, importer compatibility, any, unused vars, hook dependency arrays.
ComponentReviewerT2
Judgment only: composition pattern, scope placement, concern mixing, client boundary, Radix-vs-hand-rolled, accessibility.
The compiler is the importer check
tsc over the owning project replaced a step that searched for the exported name and read every match. Button appears in 78 files — that one step could cost more than the rest of the review. The compiler answers the same question with a file and a line.
Errors gate; warnings never do
The hygiene script was calibrated across all 140 components to a baseline of 0 errors / 68 warnings. Warnings justify PASS_WITH_WARNINGS and explicitly never FAIL — which is what keeps the three-verdict scale from collapsing into a soft pass.
A check that can't be decided at the layer holding it is worse than no check.
It produces confident wrong answers. That principle — not cost — is what assigns every check in this fleet to a script, a compiler, or a judgment gate; the tiers follow from it.

Escalation is an exit, not a retry

After repeated failure the decision goes to the main agent or a human instead of an automatic model change (ADR 0013). The orchestrator never promotes a struggling agent to a bigger model — there is no auto-retry-on-a-larger-model edge anywhere in this system.

Three deliberate exceptions

Every sub-agent on this page is pinned in one file. These three are stated absences — read them as decisions, not gaps.
The policy file pins the 20 named sub-agents and the Sandcastle dispatcher. The interactive orchestrator's own model is user-selected per session and governed by nothing.
tools/config/agent-model-policy.json
ADR 0004 · 0012 · 0013 · 0014
TestRunner is inherit
The one agent whose cost is caller-dependent. Its T1 role is fixed; its model is whatever the session runs.
Human picks the session model Orchestrator TestRunner
It inherits the orchestrator's session model, which is itself unpinned — so the fleet's one caller-dependent cost traces back to a human's session-level choice, not to a policy entry.
The /code-review axes are unpinned
The skill dispatches harness-native on purpose, so the two reviewers sit outside the policy file rather than being omitted from it.
Escalation never buys compute
Every cap ends at the orchestrator or a human. No path in the system responds to failure by moving up a tier.
