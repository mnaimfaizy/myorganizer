Alias hazard

Two skills are routinely invoked under a name that is not their directory name. A maintainer answering “which skill do I run” needs the string they actually type.

  • TYPE/commit → node commit-change-workflow  ·  implement/SKILL.md:126
  • TYPE/create-pr → node create-pull-request-workflow  ·  implement/SKILL.md:128

Inferred — these read as informal shorthand in the skill bodies. No alias registry file exists to back either name.

Upstream-Owned skills

Six of the thirty-five skills have bodies authored upstream. They are installed at project scope, committed to this repo, and listed in skills-lock.json, which is the registry check-skill-map.mjs reads to tell them from repo-native ones. Never hand-edit them: an edit is lost at the next refresh and nothing warns you. They are drawn in Tier 1 like any other skill, badged UPSTREAM-OWNED, and contribute no outbound edges — their prose is someone else's writing, not this repo's routing configuration.
